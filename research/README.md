## 重要限制
本輪研究環境無法直接開啟部分網站（doi.org、Wikipedia、Steam 商店、gamedeveloper.com 等），搜尋配額也有上限。因此不少證據是根據搜尋摘要並交叉確認，各 CSV 的 `limitations_zh` 欄已逐條註明。正式決策前，請依文件 08 §7.1 核對關鍵數字。
