## 重要限制
1. 研究環境的網路政策阻擋 Steam、SteamDB、Wikipedia、Reddit、多數媒體網站，WebFetch 無法開啟原文。申請開放研究網域的環境變更也被服務拒絕。
2. 每個研究小組的搜尋配額約 40 次就用完。
3. 所有評分都是原型前的排序工具，誤差約 ±1 分，**不能取代玩家測試**。
