> 第二階段：Gameplay First（玩法優先）
> 建立日期：2026-11-09
> 與第一階段的關係：**獨立、平行、可交叉參照**。第一階段（`research/00–08`）完整保留，不修改。

## 1. 任務轉向

| | 第一階段 | 第二階段 |
|---|---|---|
| 起點 | 人生感悟 → 如何做成遊戲 | 成功機制 → 什麼本身就好玩 |
| 主題 | 必要條件 | **非必要**；評分時不得加分 |
| 核心問題 | 如何承載「偶然塑造人生」？ | 資源有限的獨立團隊，有哪些**尚未被充分探索、值得做原型**的核心機制？ |
| 成功定義 | 好玩＋餘韻＋傳播＋商業 | **分別**驗證：好玩、易懂、傳播、商業、差異化、可製作 |

## 2. 第一階段審查：可沿用的與必須修正的

### 2.1 可直接沿用（作為第二階段的輸入）
| 第一階段發現 | 第二階段用途 |
|---|---|
| 玩家先買類型，主題在後（MKT-01、12） | 支持「玩法優先」轉向 |
| 實況效果平均小且短暫（VIR-01，準實驗） | 傳播模型不得假設實況必然帶動購買 |
| 好評≠營收（GAME-B17、B18，官方） | 商業模型需分別驗證 |
| 系統型／每人結果不同 → 劇透脆弱度低（03b §5） | 傳播漏斗「參與慾望」層的候選因子 |
| 高勝率輸掉被視為不公平；輸入隨機優於輸出隨機（FUN-004、025） | 機制分類「隨機性與策略控制」 |
| 一萬碗燕麥粥（FUN-015） | 湧現式機制的主要失敗風險 |
| Steam 年約 19,000 款、評論中位數極低（VIR-11、12） | 商業基準率 |

### 2.2 第一階段的已知弱點（本階段必須改善）
1. **查證層級不清**：190 條證據中有相當比例只來自搜尋摘要。→ 本階段新增**V0–V3 查證層級**欄位（見 `data/_shared_brief_p2.md`）。
2. **網域被擋**：Steam、Wikipedia、Reddit、SteamSpy、doi.org 等無法直接開啟。本階段曾嘗試申請新的研究環境以開放這些網域，但**服務拒絕了請求**，因此限制仍然存在。
3. **中文圈、手機、網頁平台資料薄弱**：本階段的兩個指定案例（《80億分之1》、《塗鴉躲貓貓》）正好補這個缺口。
4. **評分由單一研究員給出**：本階段的評分模型會明確寫出每一分的理由與證據層級，並對前段概念做反方審查。

## 3. 研究問題（依優先序）

### P0：核心問題
- **Q1**：什麼機制能讓玩家**每玩一局都有機會產生值得分享的內容**？
- **Q2**：哪些機制以**極簡規則**創造**高樂趣密度**與**長期深度**？
- **Q3**：哪些尚未被充分探索的**機制組合**，小團隊做得出來？

### P1：案例問題
- **Q4**：《80億分之1》為什麼讓人點進來、玩完、分享？流量轉換成了多少付費？
- **Q5**：《塗鴉躲貓貓》為什麼「畫得爛也好玩」？熱潮怎麼來、怎麼退？
- **Q6**：哪些遊戲討論度高卻沒有轉換成銷量？哪些看起來好玩但很快流失？
- **Q7**：觀看體驗與遊玩體驗在哪些遊戲中落差最大？

### P2：可行性問題
- **Q8**：單人 vs 多人、免費 vs 低價 vs 中價，在成本、風險、收益上的實際差異？
- **Q9**：小團隊最常低估的技術與營運問題？
- **Q10**：上市後的衰退曲線與長尾？

## 4. 研究架構與分工

| 代號 | 研究內容 | 交付文件 | 證據前綴 |
|---|---|---|---|
| R1 | 指定案例 A《80億分之1》、B《塗鴉躲貓貓》深度研究 | 01（指定案例專章） | `CA-`、`CB-` |
| R2 | 擴大案例：派對／社交／物理／合作背叛／直播（≥15 款） | 01（擴大案例 I） | `G2-S` |
| R3 | 擴大案例：極簡深度／Roguelike／湧現／創造／長期驗證（≥15 款）＋ ≥8 款失敗對照 | 01（擴大案例 II） | `G2-L`、`G2-F` |
| R4 | 機制分類（≥16 類）與玩家心理學 | 02 | `MX-`、`PS2-` |
| R5 | 傳播漏斗模型＋商業模式與開發可行性 | 03、04 | `VF-`、`BZ-` |

**順序原則**：先查證（R1–R5 平行）→ 再分析（02–04 整合）→ 最後才提出創意（05–08）。概念庫（05）**必須**在案例與機制研究完成後才撰寫。

## 5. 評估模型預告（詳見文件 06）

十項準則，**各自獨立評分**，不得互相替代：

| 準則 | 定義 | 主要證據來源 |
|---|---|---|
| 核心遊戲性 | 去掉主題、畫面後仍好玩的可能性 | 02 機制分類、01 案例 |
| 重玩價值 | 第 10 局仍想玩的可能性 | 01 留存資料 |
| 新手理解門檻 | 10 秒看懂、1 分鐘上手 | 03 漏斗第 2 層 |
| 創新與差異化 | 與最近似的既有作品之實質差異 | 01 案例庫 |
| 傳播潛力 | 每局產生可分享內容的機率 | 03 漏斗第 5、6 層 |
| 商業可行性 | 付費轉換的可能性 | 04 |
| 開發成本 | 小團隊做出 MVP 與完整版的成本 | 04 |
| 技術風險 | 網路、物理、AI、伺服器等不確定性 | 04 |
| 競爭強度 | 同類作品的密度與頭部壟斷 | 01、04 |
| 可測試性 | 能否用 1–2 週原型驗證核心假設 | 07 |

每一分都要標示：**證據支持的優勢**／**合理但未驗證的假設**／**高度不確定的推測**。

## 7. 已知限制（事先聲明）

1. 網路政策阻擋 Steam、Wikipedia、Reddit 等主要資料來源；申請開放研究網域的請求被服務拒絕。所有無法開啟原文的結論，都會標為 V2／V3。
2. 搜尋配額有限，每個研究小組大約 50 次查詢。
3. 「好玩」最終只能由玩家測試回答。本階段的所有評分都是**原型前的優先排序工具**，不是預測。
