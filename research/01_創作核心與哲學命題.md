# 01｜創作核心與哲學命題

> 本文件是整個研究的「北極星」。後續所有研究與設計方向，都要回頭檢查：**有沒有扭曲這裡寫下的東西？**
> 標記說明：本文件多為【推論】與【假設】，屬創作意圖的整理，而非實證結論。心理學依據見文件 02。

## 1. 原始感悟（保留原文精神）

一位以前的朋友原本打籃球，因為某個契機被找去打排球。現在，排球已經是他生活的一部分。

由此產生的感悟：

> 人生中有非常多事情，在發生的當下只是一件普通的事，甚至覺得不怎麼樣。
> 但過了很久以後才發現，那件事可能在你沒有察覺的情況下，影響了你一輩子。
> 有些事令人記憶深刻；有些事卻在不知不覺中，慢慢成為了自己的一部分。

### 1.1 這個故事裡真正「有趣」的結構

把排球這個例子拆開，可以看到五個層次。這五層，就是遊戲需要承載的東西：

| 層次 | 在排球故事中 | 對應的抽象結構 |
|---|---|---|
| ① 契機 | 「某個契機」被找去 | **外部偶然**：不是自己選的，是別人、環境、時機帶來的 |
| ② 當下的平凡 | 當時大概只是「去打打看」 | **當下價值未標記**：事件發生時沒有被標記為「重要」 |
| ③ 不知不覺的重複 | 一次、兩次、變成每週 | **累積與強化**：重複 → 習慣 → 人際圈 → 身分 |
| ④ 路徑改變 | 籃球的那條路，漸漸不再走 | **機會空間的改變**：開啟一些路，也悄悄關閉另一些 |
| ⑤ 旁觀者的回望 | 創作者「看到他的貼文」才意識到 | **事後回顧的驚奇**：理解發生在很久以後，而且往往是透過別人、或透過某個偶然的回看 |

**特別值得注意的是第 ⑤ 層**：這份感悟不是朋友本人說的，而是創作者在看別人的人生時產生的。這暗示了一個可能的設計線索——**驚奇感也許更容易在「看見」一段人生軌跡時產生，而不只是在「活過」它時產生。**【推論】

## 2. 核心命題

### 命題 1：當下感受與長期影響不對等
當下覺得微不足道的事，可能有長遠影響；當下天崩地裂的事，可能隨時間失去影響力。

### 命題 2：人生不只由有意識的重大選擇構成
大量的人生走向，來自偶然的邀請、一次對話、一個習慣、一次接觸新環境的機會。

### 命題 3：人往往是先「做」，後來才「成為」
興趣與自我認同，常常是行為、關係與環境累積的結果，而不是起點。

### 命題 4：路徑依賴，但非決定論
過去改變了未來的選擇空間；但同一件事，在不同人、不同環境、不同後續選擇下，會走向完全不同的結果。

### 命題 5：我們對人生的理解具有事後建構性
回顧時，我們容易把某事件說成「命運的轉折點」。這可能部分是真的，也可能部分是記憶與敘事的重建。

### 命題 6：重要的不是改變命運，而是看見人生如何形成
遊戲的終點不是「你成功改變了結局」，而是「你看見了自己是怎麼變成這樣的」。

## 3. 情感目標

### 3.1 我們想要的反應（目標情緒）
- 「原來那個時候的事情，竟然影響了這麼多。」——**驚奇**
- 「我完全沒有想到，自己會變成現在這樣。」——**陌生化的自我認識**
- 「如果當初沒有發生那件事呢？」——**反事實好奇**（不是後悔）
- 「原來我現在的某些習慣，是從那個時候開始的。」——**溯源的發現感**

### 3.2 情緒光譜定位

```
  遺憾 ─── 懷舊 ─── 【驚奇】 ─── 感恩 ─── 勵志
                      ▲
         目標落點：中性偏溫暖、帶有好奇
         不是「早知道就好了」，也不是「一切都是最好的安排」
```

### 3.3 明確不想要的反應
| 不想要 | 原因 |
|---|---|
| 「早知道就選另一個」（純遺憾） | 會把遊戲變成最佳化解謎，玩家開始查攻略 |
| 「一切都是命中注定」（宿命論） | 違背命題 4，也剝奪玩家能動性 |
| 「好喔，遊戲又要我感動了」（被操弄感） | 違背「玩家自己發現」的原則 |
| 「這只是隨機的」（虛無感） | 違背因果可理解性，玩家會覺得不公平 |
| 「做好事就有好結局」（道德帳本） | 違背「影響不一定正面或負面」 |

## 4. 哲學矛盾（必須保留，不可強行消解）

這些矛盾是創作的張力來源，不是需要「解決」的 bug。後續設計應該**承載**它們，而不是選邊。

### 矛盾 1：偶然 vs 因果
如果一切都是偶然，人生就沒有意義可以「發現」；如果一切都有清楚因果，就沒有偶然的驚奇。
→ 真實人生似乎是：**事前不可預測，事後可部分追溯，但追溯本身也不完全可靠。**

### 矛盾 2：能動性 vs 被塑造
玩家需要感覺「我在做選擇」，否則沒有遊戲性；但主題說的是「環境也在塑造你」。
→ 也許最好的體驗是：**玩家確實在選擇，但選擇的「選項本身」是被過去悄悄塑造出來的。**

### 矛盾 3：「發現意義」vs「事後建構意義」
我們希望玩家驚奇地發現「那件小事影響了一切」；但心理學告訴我們，這種發現本身可能是事後建構的敘事。
→ 誠實的遊戲也許應該讓玩家**同時感受到兩件事**：「它真的影響了我」以及「但也許不是只有它」。

### 矛盾 4：可重玩性 vs 一次性頓悟
「原來是那件事！」的驚奇，第二次玩時可能就失效了（玩家已經知道）。但商業上需要重玩價值。
→ 這是本專案最大的設計難題之一，見文件 05、07。

### 矛盾 5：好玩 vs 餘韻
「好玩」通常需要清楚回饋、掌握感、快速循環；「餘韻」通常需要留白、緩慢、不確定。
→ 兩者也許不需要在同一個時刻發生，可以**分布在不同的時間尺度**上。【假設】

### 矛盾 6：普遍性 vs 個人性
感悟來自一個非常個人的瞬間（看到朋友的貼文），但商業遊戲需要普遍共鳴。
→ 也許答案是：**機制提供普遍結構，內容由每個玩家的遊玩歷程填入**，讓「個人性」由玩家自己產生。【假設】

## 5. 不應被簡化或扭曲的部分（守門清單）

設計方向在每個階段都要通過以下檢查：

- [ ] **不是**「選擇改變命運」。重點不在選擇的力量，而在**沒被當成選擇的小事**的力量。
- [ ] **不是**蝴蝶效應式的戲劇反轉。不是「你踩死一隻蝴蝶，世界毀滅」，而是**慢慢滲透**的影響。
- [ ] **不是**道德評分。影響可正可負，也可以既正又負。
- [ ] **不是**旁白說教。玩家必須自己看見，而不是被告知。
- [ ] **不是**預先寫死的「伏筆回收」。如果每個小事件都是編劇安排好的伏筆，那就是在說「人生有劇本」，與命題 4、5 相違。
- [ ] **要包含**「不知不覺」：有些影響應該是玩家**完全沒注意到**的，而不只是「玩家注意到但不知道結果」。
- [ ] **要包含**「重大事件的淡化」：不只小事變大，大事也可能變小。
- [ ] **要包含**多因共成：重要結果不應總能追溯到單一原因。

## 6. 創作者願景的一句話版本（供團隊內部對齊）

> **讓玩家先玩得開心，再對自己的經歷感到驚奇，最後對人生產生一點不同的理解。**

更具體的體驗弧線：

```
  時間 →
  [好玩]──────────────────────────────────────▶ 持續
        [不經意的小事]  (玩家幾乎沒注意)
                  [累積、分岔、習慣成形]  (玩家專注於玩法本身)
                                 [回望的時刻]  ← 驚奇發生點
                                         [餘韻：如果當初…？]  ← 可能促成重玩或分享
```

## 7. 留待研究驗證的關鍵假設

| 編號 | 假設 | 驗證方式 |
|---|---|---|
| H-01 | 「回望」時刻產生的驚奇，強度足以成為分享動機 | 原型測試＋訪談 |
| H-02 | 玩家可以在「沒有被提示」的情況下，自己注意到早期小事件的影響 | 原型測試（觀察而非詢問） |
| H-03 | 系統生成的因果比手寫伏筆更能產生「這是我的故事」的感受 | A/B 原型 |
| H-04 | 「看別人的人生軌跡」能產生與「活過自己的」相當或更強的驚奇 | 原型測試 |
| H-05 | 驚奇感可以在重玩中透過「不同的小事件」持續產生，而非只有一次 | 多次遊玩測試 |
| H-06 | 玩家不在乎主題時，核心玩法仍然可以獨立成立 | 去主題化原型測試 |

這些假設將在文件 06–08 中與研究證據對照。
